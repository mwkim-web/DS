Spacing

GolfVX DS의 스페이싱은 4의 배수를 기본으로, 짝수 예외값 2와 14를 포함합니다. 토큰 이름은 px 값을 그대로 사용합니다 (spacing/16 = 16px).

Scale

4의 배수 기본 + 짝수 예외(2, 14).

Usage

스페이싱 토큰 사용 기준입니다.

Component 내부

컴포넌트 내부 패딩에는 spacing/8~spacing/24 사용

Section 간격

섹션 간 여백에는 spacing/32~spacing/64 사용

Page 여백

페이지 좌우 여백에는 spacing/80 이상 사용
