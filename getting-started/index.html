Getting Started

GolfVX DS는 KakaoVX의 프로덕트를 위한 디자인 시스템입니다.
디자인의 언어를 기반으로 한 코드, 리소스, UX 가이드라인으로 구성됩니다.

What is GolfVX DS

GolfVX DS는 KakaoVX의 다양한 골프 서비스를 일관되게 구성하는 데 도움을 주는 기업형 디자인 시스템입니다. 다양한 화면 크기와 구성 요소를 플랫폼에서 더 쉽고 더 집중적인 서비스를 만드는 것을 지향합니다.

Figma UI Kit GitHub Repository

Design Principles

GolfVX DS를 관통하는 3가지 핵심 원칙입니다.

Extensibility

컴포넌트의 확장성을 유지하여 구조를 설계합니다.

Consistency

일관성 있는 사용자 경험을 제공합니다.

Efficiency

제품 개발에 있어 일관된 플로로 효율성을 높입니다.

디자이너를 위한 가이드

Figma 라이브러리를 시작하는 방법입니다.

  • → 팀의 가이드 문서에 Figma의 디자인 라이브러리 팀 뷰 및 텍스트 아이템을 발견하고 팀 보고 확인해보세요.
  • → 가이드 문서와 디자인 라이브러리로써 명령 페이지 단락 Slot(Customize) 페이지를 포함합니다.
  • → Figma 라이브러리 팀 뷰에서 GolfVX DS를 활성화하세요.
  • → Variables 패널에서 Semantic 토큰이 정상 로드됐는지 확인하세요.
